## Описание проекта

Этот проект представляет собой backend-часть системы для заказа блюд быстрого питания. Система позволяет клиентам создавать заказы, модераторам и администраторам управлять заказами и блюдами, а также включает асинхронный сервис оплаты. Backend реализован с использованием фреймворка Django и базы данных PostgreSQL.

## Основные функции

- **Аутентификация и авторизация**: Пользователи могут регистрироваться, входить в систему и выходить из нее.
- **Управление блюдами**: Менеджеры могут добавлять, редактировать и удалять блюда.
- **Управление заказами**: Клиенты могут создавать заказы, добавлять и удалять блюда из заказа, а также отслеживать статус заказа. Менеджеры могут одобрять или отклонять заказы.
- **Асинхронный сервис оплаты**: Сервис проверяет оплату заказа и обновляет его статус.

## Технологии

- **Язык программирования**: Python 3.10+
- **Фреймворк**: Django 4.1+
- **База данных**: PostgreSQL 14
- **Асинхронный сервис**: Go
- **Дополнительные технологии**: Redis, MinIO

## API

### Блюда

- GET /api/dishes/: Получить список блюд с фильтрацией.
- GET /api/dishes/int:pk/: Получить подробную информацию о блюде.
- POST /api/dishes/post/: Добавить новое блюдо.
- PUT /api/dishes/int:pk/put/: Изменить информацию о блюде.
- DELETE /api/dishes/int:pk/delete/: Удалить блюдо.

### Заказы

- GET /api/orders/: Получить список заказов с фильтрацией.
- GET /api/orders/int:pk/: Получить информацию о заказе.
- PUT /api/orders/int:pk/put/: Изменить заказ.
- PUT /api/orders/accept/: Изменить статус заказа (пользователем).
- PUT /api/orders/int:pk/confirm/: Изменить статус заказа (модератором).
- DELETE /api/orders/int:pk/delete: Удалить заказ.

### Аутентификация

- POST /user/login/: Аутентификация.
- POST /user/logout/: Выйти из системы.
- POST /user/: Создать новый аккаунт.
- POST /user_info/: Получить информацию о пользователе.

### Асинхронный сервис

- POST /calc/: Обработать ответ от второго сервиса.
